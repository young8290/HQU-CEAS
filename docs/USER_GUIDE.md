# 用户手册(USER_GUIDE)

按角色的完整功能手册,以系统内**侧边栏三个分组**为纲:综测系统、申报系统、平台。第一次使用请先走 [QUICKSTART.md](QUICKSTART.md) 的角色路线;评定条件、分数组成、名额规则等业务口径见 [BUSINESS.md](BUSINESS.md)。

系统内随处可得的帮助:登录后「平台 → 新手指引」(`/guide`)按角色列出操作顺序;综测/申报页面顶部有「操作指南」按钮,可直接预览对应 PDF(同 [附:官方操作指南 PDF](#附官方操作指南-pdf))。

## 管理员手册

### 综测系统

| 菜单 | 功能 |
| --- | --- |
| 综测总览 | 查看全院或指定年级、班级的综测数据准备情况与统计信息,跟进各班填报/审核进度 |
| 分数管理 | 按班查看全部学生分数;维护管理员权限项(学业学术素质、体育基础分、社区表现分);一键重算班级总分、校验分数完整性。**管理员直接改分默认关闭**,需在「系统设置」打开「允许管理员修改分数」开关(防误改) |
| 学生管理 | 学生增删改查;「下载模板」→ 批量导入全院或指定班级学生(缺失年级/班级自动补建);支持按年级/按班级批量删除 |
| 数据导入 | 导入教务**学业成绩表**(按绩点折算学业学术素质分)与**体测/体育课成绩表**(折算体育基础分);查看导入日志与失败明细(所在行、学号、姓名、原因) |
| 附件导出 | 导出指定班级**附件 2**(成绩汇总表)、**附件 4**(简表),按年级打包全部班级附件 ZIP;导出导入失败记录、班长账号清单 |

### 申报系统

| 菜单 | 功能 |
| --- | --- |
| 申报数据导入 | 导入**外部奖项名单**(国奖/国励/校奖,用于互斥校验与标签)、**院奖名额金额表**(控制各班名额与可支配金额)、**先进班级名单**(影响优干班级推荐名额)、**班长邮箱** |
| 申报审核 | 查看奖学金/荣誉称号申报批次列表与详情;核对申报学生、条件快照、确认项与班长签署的确认协议 PDF;填写审核意见后「退回修改」或「确认通过」(荣誉称号通过时可确认最终获奖级别);通过后自动为学生写入申报通过标签 |
| 国家奖学金 | 平行班合组与稳健择优评定,见下节[国家奖学金评定操作流](#国家奖学金评定操作流) |
| 申报材料导出 | 导出申报汇总、院奖分配表、荣誉称号明细、附件 2 申报汇总表、**签字名单**(上交学术部存档)、邮件发送记录 |
| 标签视图 | 按学年/班级查看学生标签(外部奖项、申报通过等),用于核对互斥与获奖情况 |

### 国家奖学金评定操作流

落实《国家奖学金评定办法完善方案》的独立评定模块(算法口径见 [BUSINESS.md](BUSINESS.md#国家奖学金评定平行班合组与稳健择优)),不影响院奖/荣誉申报流程。页面:申报系统 → 国家奖学金(`/declaration/national-scholarship`),仅管理员可见。

| 步骤 | 在页面上做什么 |
| --- | --- |
| 1. 建评比单元 | 在「评比单元」面板点「新建评比单元」:选择年级 → 点「建议平行班」自动勾选同培养方案的平行班(可手工调整)→ 填名额 `Q`、入池比例 `p`(默认 10%)、参数 `w`(默认 0.5)、`d`(默认 1.0)→ 创建 |
| 2. 计算/重算 | 在单元上点「计算/重算」,系统生成候选池与分层;「评比单元详情」显示班级效应上界三值:`B_解析(w·d)`、`B_经验(分位差中位数)`、`B_最终(取小)` 及 Q/p/w/d 参数 |
| 3. 核对候选池(算法一) | 「候选池」面板逐行显示入池来源:班级推荐 L ∨ 绩点前 p(J)∨ 综测前 p(K)∨ 重大成果 M;可在候选行上修正「班级推荐/重大成果」旗标后重算 |
| 4. 查看分层(算法二、三) | 「分层比较表(表 A-1)」按稳健占优关系给出稳健层名次(`g` 差超过 `B` 且 `z` 不更低才构成占优),与任何人互不占优者标记为**临界层** |
| 5. 临界层评议(算法四) | 在「临界层结构化评议」面板对临界层逐人录入书面评议理由、最终次序与是否入选——不设综测折算绩点兑换率,取舍由书面理由承担 |
| 6. 导出留痕 | 导出表 A-1 候选人比较表 Excel(班级/学号/g/z/专业名次/入池来源/稳健层名次/是否临界层/成果/评议理由/最终次序/是否入选),作为公示与复核依据 |

## 班长手册

### 综测系统

| 菜单 | 功能 |
| --- | --- |
| 本班综测总览 | 本班数据看板:填报进度、审核状态一览 |
| 本班综测 | 编辑班长权限分数项(德育、创新与实践、体育奖励、美育、劳动教育、公益服务、附加分);每项用「明」按钮登记加/减分明细;输入自动保存,体育总分与综测总分自动计算。各项满分与口径见 [BUSINESS.md](BUSINESS.md#综测分数组成) |
| 审核小组确认 | 维护审核小组成员(默认生成班长/团支书/学习委员三类,可改后保存);为每位成员**生成专属审核邀请链接**(可撤销重发);实时查看每位成员对每名学生的核对进度、异议说明与操作日志;采集成员签名,全员签完自动生成《班级综合素质测评审核小组确认书》PDF 并标记本班审核完成 |
| 数据导入 | 下载「个人综测填写表」模板发给同学;回收后**批量导入**(一次最多 100 份),自动写入各分项加分明细;查看失败明细 |
| 附件导出 | 导出**本班**附件 2 |

### 申报系统

| 菜单 | 功能 |
| --- | --- |
| 申报数据导入 | 导入本班**申报补充信息**(性别、处分、任职、竞赛活动、优秀学生/优干申报意愿与级别、备注;平均绩点由系统按 `学业学术素质分/8−2.5` 自动计算,无需填写) |
| 奖学金申报 | 查看系统按条件生成的**候选名单**(不满足条件或与国奖/国励/校奖互斥者显示原因);查看**院奖分配预览**(按综测总分排序,一/二/三等 1000/800/600 元,自动校验名额、金额与等级人数递增约束);勾选名单 → 完成确认项 → 在线签署班长确认协议 → 提交批次 |
| 荣誉称号 | 选择**优秀学生**/**优秀学生干部**候选(优干区分班级推荐与学生会推荐,先进班级推荐名额 2 人、普通班级 1 人);维护申报级别、推荐来源、任职情况、竞赛活动与备注 → 确认项 → 签名 → 提交 |
| 提交记录 | 跟踪各批次审核状态与审核意见;查看已归档的确认协议 PDF;被退回时修改后重新提交 |

> 提交前置条件:本班综测审核已完成(确认书 PDF 已生成)且申报系统开放;提交时后端会再次校验候选条件、确认项、签名与名额金额限制。

## 审核成员手册

审核成员是班长邀请的本班同学(如团支书、学习委员),**无需注册账号**。

| 环节 | 说明 |
| --- | --- |
| 邀请登录 | 打开班长发来的专属链接(`/review-login`),系统校验邀请令牌并**绑定当前访问设备**;换设备需班长撤销后重新生成链接 |
| 分数核对 | 在核对页(`/review/scores`)查看本班每名学生的各项分数与加分明细;对每人标记「已核对」或「有异议」(异议必须填写说明) |
| 本人签名 | 核对完成后在页面底部手写签名或上传签名图片;签名仅用于本班审核确认书 |
| 状态同步 | 核对状态、签名状态与操作日志通过 WebSocket 实时同步到班长端;全组签名后确认书 PDF 自动生成/更新 |
